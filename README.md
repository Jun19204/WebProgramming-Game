# SKY STRIKE — 게임 플레이 안내

F-22A 전투기를 조종해 군도 상공의 적기를 격추하는 1인용 공중전 게임입니다.
**6분 안에 적기 5대를 모두 격추**하면 미션을 클리어합니다.


## 1. 게임 실행하기

1. 압축 파일로 받았다면 폴더 전체를 압축 해제합니다.
2. [index.html](index.html)을 더블클릭해 웹 브라우저로 엽니다.
3. 로비에 **ALL SYSTEMS GREEN**이 표시되면 **출격하기**를 누릅니다.

인터넷 연결이나 별도 설치 없이 실행할 수 있습니다. PC 키보드와 WebGL2·WebAssembly를 지원하는 브라우저가 필요합니다. `index.html`과 `assets`, `src`, `vendor` 폴더는 함께 보관하세요.

로비에서는 전투기 보기 영역을 **마우스로 드래그**해 기체를 돌려볼 수 있습니다. **시점 초기화**를 누르면 기본 시점으로 돌아갑니다. 로비 음악은 브라우저의 자동재생 제한 때문에 첫 클릭이나 키 입력 후 시작합니다.


## 2. 조작키

| 키 | 동작 |
| --- | --- |
| ↑ / ↓ | 기수 올리기 / 내리기 |
| A / D | 왼쪽 / 오른쪽으로 기울이며 선회 |
| ← / → | 왼쪽 / 오른쪽으로 방향 조정 |
| W / S | 추력 증가 / 감소 |
| Space | 기관포 연사 — 탄약 무제한 |
| Shift | 선택한 적에게 락온 후 미사일 발사 |
| Tab | 표적 변경 |
| F | 플레어 연속 방출 — 출격당 5회 |
| C | 3인칭 추적 시점 ↔ 1인칭 조종석 시점 |
| Esc | 일시정지 / 재개 |

**A + ←** 또는 **D + →**를 함께 누르면 더 강하게 선회할 수 있습니다. 기수와 기울기 조작키를 놓으면 수평 자세로 돌아가도록 보조합니다.

다른 창으로 이동하면 게임이 자동으로 일시정지됩니다. 게임으로 돌아온 뒤 **비행 재개** 또는 **Esc**를 눌러 직접 재개하세요.


## 3. 첫 출격 순서

1. **Tab**으로 공격할 적을 선택합니다.
2. 방향키와 **A/D**로 표적을 화면 중앙에 맞춥니다.
3. 표적을 조준한 채 잠시 유지해 **LOCKED / 발사 가능** 표시를 기다립니다.
4. **Shift**로 미사일을 발사합니다.
5. 격추 후 다음 표적을 공격하며, 미사일 접근 경고가 뜨면 회피합니다.

출격 시 **체력 100%, 미사일 20발, 플레어 5회**가 지급됩니다. 기관포 탄약은 무제한입니다.


## 4. 적기 공격하기

### 유도미사일

선택한 적이 **4km 이내**에 있고 기수 정면에서 약 **22도 이내**에 들어오도록 조준하세요. 약 **0.65초** 동안 조준을 유지하면 락온됩니다. 섬이 표적을 가리거나 조준 범위를 벗어나면 락온이 풀립니다.

**LOCKED**가 표시되면 **Shift**를 누릅니다. 미사일은 명중 시 적기를 한 발로 격추할 수 있지만, 표적의 기동이나 지형 때문에 빗나갈 수 있습니다. 다음 발사까지는 최소 0.65초가 필요합니다.

### 기관포

**Space**를 누르고 있으면 기수 방향으로 연사합니다. 움직이는 적의 현재 위치보다 진행 방향을 조금 앞서 조준하세요.

### 적의 반격

적은 출격 직후부터 추격을 준비하고 기관포와 유도미사일로 공격합니다. **적기 수가 줄어들수록 남은 적의 추격·연사·미사일 공격이 강해집니다.** 마지막 적까지 경계를 늦추지 마세요.

적기를 격추해도 그 적이 이미 발사한 미사일은 계속 날아옵니다. 격추 직후에도 접근 경고를 확인하세요.


## 5. 미사일 회피하기

### 플레어 사용

플레이어를 추적하는 적 미사일이 약 **2.5km 이내**로 접근하면 경고 문구와 경고음이 나옵니다. 이때 **F**를 눌러 플레어로 미사일 유도를 교란하세요.

- 한 번 사용하면 좌우 2발씩 5차례, **총 10발**이 연속 방출됩니다.
- 연속 방출 한 묶음에 사용 횟수 **1회**를 소모합니다.
- 출격당 **5회** 사용할 수 있으며, 재사용 간격은 **1.2초**입니다.
- HUD의 **F / FLARE** 표시에서 남은 횟수를 확인할 수 있습니다.
- 플레어는 무적 기능이 아닙니다. 너무 가까워진 미사일은 회피 기동을 함께 해도 맞을 수 있습니다.

### 급선회로 회피

플레어 없이도 접근 타이밍에 맞춰 **A + ←** 또는 **D + →**로 급선회하면 미사일을 피할 수 있습니다. 충돌 직전까지 기다리기보다 약 1~2초의 반응 여유를 두세요. 접근 방향과 속도에 따라 성공 여부가 달라집니다.

적 미사일에 한 번 맞으면 체력이 **25%포인트** 감소합니다. 다른 피해가 없다면 네 번 피격 시 기체를 잃습니다.

## 7. 클리어와 실패

**6분 안에 적기 5대를 격추하면 클리어**합니다. 짧은 관제 무전이 끝나면 결과 화면이 나타납니다. 클리어 대사는 음성으로만 재생됩니다.

무전 중에도 방향 조작·추력 조절·시점 전환이 가능합니다. 이때는 승리와 기록 시간이 확정되어 추가 피해가 기록되지 않습니다. 일시정지하면 비행과 무전도 함께 멈춥니다.

전투 중 아래 상황에서는 미션에 실패합니다.

- 체력이 0이 됨
- 해수면·섬·다른 기체와 충돌
- 6분의 제한 시간이 지남
- 작전 중심에서 반경 **10.5km**를 벗어나 **15초 안에 복귀하지 못함**

결과 화면에서 **다시 출격**으로 재도전하거나 **브리핑으로 돌아가기**로 로비에 복귀할 수 있습니다.


## 8. 설정과 플레이 요령

로비 또는 일시정지 화면의 **설정**에서 다음 항목을 바꿀 수 있습니다.

- **효과음 · 무전 볼륨**: 엔진·무장·폭발·대사 소리
- **배경음악 볼륨**: 로비 음악 소리
- **음소거**: 모든 소리 끄기
- **화면 흔들림 · 메뉴 움직임**: 시각 효과 조절

설정은 브라우저가 저장을 허용하면 유지됩니다.

처음에는 3인칭으로 적의 위치와 비행 방향을 익히세요. 근접전에서 같은 방향으로 계속 돌기만 하면 표적을 잡기 어려울 수 있습니다. 추력을 조절하거나 거리를 벌린 뒤 다시 접근해 보세요. 저고도에서 급선회할 때는 적뿐 아니라 해수면과 섬도 주의해야 합니다.


## 9. 실행이 잘 안 될 때

- **빈 화면 또는 초기화 실패**: 압축을 완전히 풀었는지, 필요한 폴더가 함께 있는지 확인한 뒤 새로고침하세요.
- **소리가 안 남**: 게임 화면을 한 번 클릭하고, 게임 설정의 음소거·볼륨과 브라우저 탭 및 Windows 볼륨을 확인하세요.
- **키가 반응하지 않음**: 설정·조작 가이드 창을 닫고, 일시정지 상태라면 직접 재개하세요.
- **상태를 점검하고 싶음**: [tests.html](tests.html)을 열면 설치 없이 현재 브라우저에서 오프라인 진단을 실행할 수 있습니다. 검증 범위는 [TESTING.md](TESTING.md)에 기록되어 있습니다.
